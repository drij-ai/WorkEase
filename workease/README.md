# WorkEase

WorkEase is an employee management system built using Python and Django.

## Requirements
- Python 3.13.5
- Django 6.1.1

## Setup Instructions

1. Install Python.
2. Open the WorkEase project folder in VS Code.
3. Open the terminal.
4. Install the required packages:

   pip install -r requirements.txt

5. Run database migrations:

   python manage.py migrate

6. Start the server:

   python manage.py runserver

7. Open your browser and visit:

   http://127.0.0.1:8000/

## Features
- Employee management
- Attendance tracking
- Leave management
- Payroll management
- Admin dashboard

## Database
WorkEase uses SQLite for database storage.
